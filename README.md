# VRK DETAILING — концепт сайта для Воркуты

Независимая демонстрационная версия. Не официальный сайт и не заказ, согласованный с мастерской. Для локального предпросмотра откройте `index.html` — интернет для графики и работы функций не требуется. Архив также содержит `preview-offline.html`, в котором всё встроено в один файл.

## Состав

- `index.html` — главная страница.
- `styles.css` — адаптивные стили.
- `script.js` — фильтры и модальные окна кейсов, сравнение эскизов, выбор услуг, подготовка текста заявки, локальный предпросмотр фото, мобильное меню.
- `assets/` — 13 оригинальных векторных изображений (SVG, включая favicon). Никакие внешние фотографии не используются.
- `preview-offline.html` — автономная версия одним файлом.
- `previews/` — скриншоты главной, мобильной версии и разделов.
- `vercel.json`, `robots.txt` — блокировка индексации на этапе демо.

## Публикация в Vercel

1. Разместите содержимое этой папки в корне GitHub-репозитория.
2. Импортируйте репозиторий в Vercel, Framework Preset: **Other**.
3. Build command — **пустой**, output directory — **пустой**; деплой без npm.
4. До коммерческого запуска необходимо подтвердить данные, разрешение на бренд/фотографии, условия и удалить режим `noindex`, если сайт стал официальным.

## Функции и ограничения

- Кнопки выбора услуг и готовых сценариев отмечают нужные пункты формы.
- По каждому кейсу доступна подробная карточка и переход к похожей заявке.
- Кнопка «Подготовить заявку» не записывает посетителя и не передаёт данные кому-либо. Заявка копируется в буфер; после перехода в VK посетитель вставляет её вручную.
- До 3 изображений JPG/PNG/WEBP до 8 МБ каждое могут быть локально показаны и удалены. Файлы **никуда не отправляются и не сохраняются**.
- Нет придуманного прайса, скидок, отзывов, свободных окон, сертификатов или гарантированного результата ухода.
- Сценарии «Ухоженный кузов / Свежий салон / Всё в порядке» — лишь варианты заполнения заявки, а **не официальные пакеты VRK**.
- Слайдер «до/после» показывает две созданные SVG-схемы, а **не фотографии реальной работы**.
- Для коммерческой версии рекомендуется получить разрешённые фотографии работ, актуальные цены и подробную геометку, настроить при необходимости полноценную форму и договориться с владельцем.
